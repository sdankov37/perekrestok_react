# Lighthouse-аудит доступности

1. Открыть проект: npm run dev
2. Chrome → F12 → вкладка Lighthouse
3. Mode: Navigation, Device: Mobile, Categories: только Accessibility
4. Analyze page load
5. ⋮ → Save as HTML
6. Сохранить в эту папку: index.html, catalog.html, product.html, account.html, contacts.html, about.html
7. git add lighthouse/ && git commit -m "Работа 13: Lighthouse accessibility"
